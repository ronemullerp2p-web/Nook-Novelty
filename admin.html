Email Settings

Outgoing mail server (SMTP)

SMTP details for your outgoing mail server (your email provider's "SMTP" settings). Used for order emails, low-stock alerts and QR code emails. Using Gmail (smtp.gmail.com)? Your normal Gmail password won't work here — turn on 2-Step Verification under Google Account > Security, then create an App Password and use that as the password below. Use port 465 with "Use TLS from the start" ticked. (Ports 25 and 587 are blocked on the server this app runs on.)

If "Send test" fails with something like "self-signed certificate in certificate chain", your mail server is using a certificate that isn't publicly trusted (common with small or company mail servers). Ticking this box works around it, but means the app can no longer tell your real mail server apart from an attacker pretending to be it — only enable it if you understand and accept that. Gmail never needs it. Note: the server this app runs on may not allow skipping the check; if the error stays, the mail server needs a proper certificate.

Tests the settings shown above, even before you save them.
